# قائمة التسليم والقبول / Customer acceptance checklist

تملأ مع العميل قبل التسليم. ليست عقد بيع أو إثبات تحويل بنكي.
Complete with the customer before handover. This is not a sales contract or proof of bank transfer.

- [ ] اسم النادي وبريد المالك ورابط الخدمة والخطة والتواريخ ووسيلة الدعم مكتوبة في النموذج.
      Club name, owner email, URL, plan, dates and support contact recorded.
- [ ] المالك أنشأ كلمة مروره بنفسه وأكد البريد واختار النادي الصحيح.
      Owner created their own password, confirmed email and selected the correct club.
- [ ] الترخيص نشط وحدود الفروع والأعضاء والموظفين مناسبة للاتفاق.
      License active and branch/member/staff limits match the agreement.
- [ ] الشعار والثيم واللغة والعملة والمنطقة الزمنية والفروع مراجعة.
      Logo/theme/language/currency/timezone/branches verified.
- [ ] الموظف انضم بكود دعوة خاص به، وتم اختبار صلاحياته وفروعه.
      Employee joined with their invitation and role/branch scope was tested.
- [ ] تم توضيح أن الاستقبال للقراءة فقط، ولم يعط دور مالك كحل التفافي.
      Read-only reception limitation explained; ownership was not used as a workaround.
- [ ] عضو تدريبي وكارت جديد وسيريال بأصفار أولى وحضور وتكرار مرفوض تم اختبارها.
      Demo member, issued card, leading-zero serial, check-in and duplicate rejection tested.
- [ ] اختبار قارئ فعلي وطابعة فعلية قبل دفعة كروت نهائية.
      Physical reader/printer tested before production card batches.
- [ ] مراجعة تجديد وتجميد وحجز وقائمة انتظار وبرنامج تدريبي وفاتورة ومخزون ومبيعات في بيئة تجربة.
      Renewal/freeze/booking/waitlist/training/invoice/stock/sales reviewed in a test environment.
- [ ] ملف صوت محلي ورسالة عربي وإنجليزي ونداء مجدول جربت على السماعات الفعلية.
      Local music, Arabic/English messages and scheduled speech tested through actual speakers.
- [ ] منصة الموسيقى بحساب العميل والمنطقة جربت، أو سجلت كغير مختبرة.
      Provider playback with customer account/region tested or recorded as untested.
- [ ] نسخة JSON حديثة نزلت وحفظت بمكان محمي؛ نقل SQLite بين حسابات Windows غير معتمد.
      Current JSON backup downloaded to protected storage; cross-account SQLite portability was not assumed.
- [ ] تجهيز الحضور دون اتصال واختبار المزامنة على جهاز الاستقبال.
      Offline attendance preparation and synchronization tested on reception device.
- [ ] مراجعة هاتف العميل والتابلت والكمبيوتر والطباعة؛ محاكاة المقاس وحدها ليست اختبار جهاز.
      Customer phone/tablet/desktop/printing reviewed; viewport emulation alone is not device acceptance.
- [ ] البيانات التجريبية مسحت بأداتها بعد المراجعة، ولم تمس بيانات حقيقية.
      Demo data cleared using its tool, with real data untouched.
- [ ] استيراد بيانات العميل أجرى بعد نسخة مصدر، وفحص العدد والأرصدة والكروت؛ المصدر محفوظ حتى القبول.
      Customer import followed a source backup/count/balance/card check; original retained until acceptance.
