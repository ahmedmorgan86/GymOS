## إصلاح جديد

كان سكربت التحقق يبحث عن ملف `apksigner` فقط، بينما Android SDK على Windows يوفر `apksigner.bat` مع `lib/apksigner.jar`. أضيف اكتشاف JAR الرسمي على Windows وتشغيله بواسطة Java مباشرة، مع دعم `ANDROID_APK_SIGNER_JAR`. يظل مسار executable الحالي مدعومًا؛ فحوص SHA-256 وعدد الموقّعين وبصمة الشهادة كما هي. نجح التحقق الفعلي للحزم الست باستخدام SDK جهاز المشروع بعد الإصلاح.
