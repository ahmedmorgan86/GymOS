# تداعيات تغيير الهوية والرابط

حالة عمل بتاريخ 28 أكتوبر 2026 — لا تعني اكتمال النقل. PR #50 هو فرع التغيير، والموقع القديم ما زال إنتاجًا حتى اختبارات التحويل.

| الجزء | الأثر والإجراء |
|---|---|
| بيانات الخادم | نفس Supabase ومعرفات الأندية والفروع. لا نقل أو حذف أو إعادة ترقيم للسجلات |
| الجلسات | cookies مرتبطة بالدومين؛ يلزم تسجيل دخول جديد على GYMEG. لا تنسخ cookies أو مفاتيح الجلسات بين النطاقات |
| تأكيد البريد والاستعادة | تحديث allowlist وSite URL وقوالب البريد إن كانت مخصصة. الروابط الصادرة سابقًا قد تتوقف عند إيقاف القديم |
| المتصفح/PWA | IndexedDB وLocalStorage وService Worker والصلاحيات مرتبطة بالأصل؛ تغيير الاسم أو بقاء manifest id لا ينقلها عبر الدومينات |
| الحضور غير المتصل | مزامنة كل العمليات على القديم قبل الإغلاق. النسخة الجديدة لا تستطيع قراءة طابور النطاق القديم بسبب حماية المتصفح |
| الموسيقى والأصوات | الملفات المحلية وإعدادات الجهاز لا تنتقل تلقائيًا؛ أعد اختيارها على النطاق الجديد. الأصوات المحلية تتطلب تنزيلًا/تهيئة جديدة عند غياب cache |
| Android | نفس package IDs مع شهادة جديدة بطلب المالك. يلزم إزالة PUSHTORQ قبل تثبيت GYMEG؛ المزامنة تسبق الإزالة. لا يوجد تحديث آلي فوق الشهادة القديمة |
| Windows | اسم assembly ومجلد GymOS المحلي والنسخ الاحتياطية محفوظة. يعالج DeploymentOrigin إعدادات gymos.json القديمة المعروفة، ويترك استضافات العملاء المخصصة كما هي |
| توقيع Windows | EXE الحالي غير موقع Authenticode. مسار المتجر المجاني يحتاج حساب ناشر وهوية حزمة وقبول MSIX؛ لا يعتبر EXE الحالي موقعًا بسبب تجهيز المسار |
| الأجهزة | USB/شبكة/تعريفات الجهاز لا تتغير بسبب اسم المنتج؛ صلاحية الكاميرا والمتصفح قد تطلب مجددًا. الكشف لا يثبت تكامل قارئ/بصمة فعلي |
| الباركود | الأكواد وأرقام العضوية ومعرفات الأعضاء ثابتة. QR التنزيل يتغير، أما QR كارت الدخول فلا يُعاد توليده عشوائيًا |
| API/الأمان | إبقاء فحص same-origin وtenant والفرع والصلاحيات. لا wildcard CORS ولا توسيع الجسر الأصلي لمجرد نجاح النقل |
| WhatsApp/SMS | الروابط اليدوية تستمر بالأرقام والقوالب المحفوظة؛ أي webhooks مزود خارجي تحتاج فحص إعداداته منفصلًا. لا إرسال فعلي ضمن المراجعة |
| SEO | canonical/sitemap/robots/social تتحدث على الدومين الجديد؛ غياب 301 بطلب المالك قد يفقد إشارات ترتيب وروابط قديمة. الفهرسة ليست فورية |
| الرابط القديم | لا يُزال قبل المزامنة وفحص الجديد وخطة رجوع. إزالة vercel.app قد تسمح بإعادة استخدام الاسم مستقبلًا؛ تُراجع مخاطرة الروابط والتطبيقات القديمة قبل التحرير |
| GitHub والإصدارات | إبقاء المستودع الحالي وتاريخ الكود، تحديث أسماء releases وروابط التنزيل. لا مفاتيح أو كلمات مرور في Git أو ZIP العملاء |
| التراجع | إبقاء النشر السابق وإعدادات الربط اللازمة إلى أن يتأكد الدخول والبيانات والتنزيل. عدم حذف deployment سابق أو قاعدة |

تحقق محلي: 235 اختبار وحدة ناجح و7 اختبارات قاعدة اختيارية متجاوزة؛ 12 مجموعة تكامل نجحت قبل تحسين الباركود الأخير. بعده نجحت 11 حالة باركود، و10 حالات ترحيل/تحقق origin على Windows، مع 16 تصنيف أجهزة وحدود الجسر. يلزم إعادة CI على آخر commit قبل الدمج. مراجعة Supabase واختبار عزل حي للقراءة فقط موثقان في التقرير المنفصل.
