## التحذيرات

1. **pg_net في public:** تحذير أمني من Supabase. الامتداد الحالي `relocatable=false`؛ لا يمكن تنفيذ ALTER EXTENSION SET SCHEMA عليه عشوائيًا. يلزم مراجعة اعتمادات الجدولة والشبكة وخطة تحديث الامتداد مع Supabase قبل أي إعادة تثبيت. لم يُحذف أو يُنقل.
   مرجع: https://supabase.com/docs/guides/database/database-linter?lint=0014_extension_in_public
2. **حماية كلمات المرور المسرّبة غير مفعلة:** تخص Supabase Auth، وليست تحقق PIN العضو الخاص بالتطبيق. يجب التأكد من أهلية الخطة وتفعيلها عند توفرها؛ لم نغيّر الخطة أو نوافق على تكلفة.
   مرجع: https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection
3. **39 ملاحظة auth_rls_initplan:** سياسات تستدعي current_setting أو دوال auth لكل صف. مرشحة لتحسين الأداء باستخدام scalar SELECT عندما تكون القيمة ثابتة للمعاملة. تحتاج اختبار تكافؤ الصلاحيات وخطط التنفيذ قبل ترحيلها.
   مرجع: https://supabase.com/docs/guides/database/database-linter?lint=0003_auth_rls_initplan
4. **6 حالات سياسات permissive متعددة:** لا تعني تسريبًا بحد ذاتها. دمجها دون الحفاظ على منطق OR لكل عملية قد يغير الصلاحيات، لذلك لا تعديل مباشر لمجرد التنبيه.
5. **6 فهارس لم تستخدم في الإحصاءات الحالية:** لا تُحذف دون فترة قياس ممثلة؛ قد تستخدم في التقارير أو توسيع الأندية لاحقًا.
