## الفحوص القابلة لإعادة التشغيل

```sh
npm ci
npm run typecheck
npm run lint
npm test
node --import ./tests/role-api-loader.mjs --test --test-isolation=none tests/role-api.integration.mjs
node --import ./tests/usability-loader.mjs --test tests/usability.integration.mjs
node --import ./tests/member-console-ui-loader.mjs --test --test-isolation=none tests/member-console-ui.integration.mjs
npm run build
```

توليد الباركود يتطلب ترقية SQL المطابقة. المهمة الخلفية لا تفعّل تلقائيًا عند رفع الملفات. لم تُنشأ ملفات Windows/APK جديدة ضمن هذه المرحلة؛ التطبيقات الحالية تحمّل الواجهة المستضافة، واختبار الأجهزة الأصلية مستقل.

## تحقق النشر النهائي — ٢٧ أكتوبر ٢٠٢٦

دُمج #43، ونجح بناء الإنتاج وفحص Windows في GitHub. نشر Vercel المطابق لـ `e0dde662` جاهز على النطاق الرئيسي. فُتحت الشاشة الموحدة وملف العضو الكامل في Morgan Club على الموقع الفعلي. فُعّلت مهمة الخروج الإداري بعد ذلك، وأثبت سجل pg_cron نجاح التنفيذ عند 23:27 UTC وإغلاق جلستين قديمتين مع الاحتفاظ بالسجلات. أعداد البيانات ما زالت 42 عضوًا و116 سجل حضور و49 فاتورة و49 دفعة. لم يُسجل حضور أو دفع اختباري على عضو إنتاجي.

نتائج الفحوص: 217 ناجحًا و7 اختبارات اتصال اختيارية متخطاة، إضافة إلى 9 اختبارات صلاحيات و12 لقابلية الاستخدام و4 لتفاعل DOM. جميع فحوص CI للطلب #43 ناجحة. لا تزال حدود اختبارات الأجهزة والضغط متعدد الاتصالات والتثبيت المادي الموضحة في الجدول قائمة.
