# معمارية النظام — GymEG

تاريخ التقرير: 29 أكتوبر 2026 — فرع codex/gymeg-full-audit-20261029، baseline ce1a426 مع تعديلات موثقة.

Next.js 16.4.2 وReact 19.2.6 يقدمان الموقع ومساحة النادي وبوابة العضو والمنصة. API يتحقق من جلسة Supabase ثم يحدد النادي والفرع والصلاحيات قبل PostgreSQL. `app/lib/database.ts` يستخدم pool محدودًا وTLS مع تحقق الشهادة.

Windows WPF/WebView2 يعرض الواجهة مع أدوات أجهزة وصوت ونسخ SQLite محلية مشفرة عبر DPAPI. تطبيقات Android أغلفة WebView أصلية مستقلة بمسارات إدارة/عضو/دعم؛ iPhone تطبيق ويب قابل للتثبيت وليس IPA. تخزين المتصفح والنطاق والجلسات ليس مشتركًا تلقائيًا بين النطاقات.

المخططات في `ARCHITECTURE_DIAGRAMS.md`، والكتالوج الفعلي في `database-schema-snapshot.json`. فهرسة الملفات لا تعني مراجعة يدوية كاملة لكل سطر.

## حدود الاستدلال

النتائج خاصة بالأدلة المتاحة وقت المراجعة. راجع issues.json ونتائج evidence؛ لا تعني الفهرسة أو نجاح mock اكتمال تجربة جهاز أو مزود خارجي.
