# تكامل التطبيقات — GymEG

تاريخ التقرير: 29 أكتوبر 2026 — فرع codex/gymeg-full-audit-20261029، baseline ce1a426 مع تعديلات موثقة.

الموقع والإدارة والعضو يستخدمون نفس API وقاعدة الأندية؛ لا يُفترض أن تشابه الأيقونة يعني مشاركة الجلسة بين WebView والمتصفح. تحقق tenant/branch في API مطلوب لكل طلب، وليس إخفاء زر في الواجهة فقط.

مسارات التحقق تشمل: تسجيل عضو، حجز كارت، تعديل الصورة، تجديد الاشتراك، الدفع، الحضور والخروج، القياسات، التدريب، رسائل العضو، صلاحيات الموظف، دعم المنصة، المخزون والتقارير. اختبارات API تتضمن سياقات غير مسجلة وفرعًا آخر وناديًا آخر.

13 مجموعة تكامل ناجحة، ويُراجع ملف النتائج لمعرفة عدد الحالات. الكاميرا والقارئ والصوت على هاتف ومزود SMS/WhatsApp غير مثبتة بهذه الاختبارات. Android الموقّع ليس اختبار تسجيل دخول فعلي.

## حدود الاستدلال

النتائج خاصة بالأدلة المتاحة وقت المراجعة. راجع issues.json ونتائج evidence؛ لا تعني الفهرسة أو نجاح mock اكتمال تجربة جهاز أو مزود خارجي.
