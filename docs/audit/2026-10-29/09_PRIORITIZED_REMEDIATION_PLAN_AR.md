# خطة الإصلاح ذات الأولوية — GymEG

تاريخ التقرير: 29 أكتوبر 2026 — فرع codex/gymeg-full-audit-20261029، baseline ce1a426 مع تعديلات موثقة.

1. تثبيت نسخة المصدر الحالية في فرع تطوير وفحص build/type/lint وAPI بعد آخر تعديل.
2. هاتف Android وiPhone: الدخول والصورة والكارت والتمرير ولوحة المفاتيح والوضع الأفقي.
3. اختبار استرجاع نسخة قاعدة منفصلة، ثم أي نقل schema مع وظائف RLS والـ cron؛ لا تغيير اسم database postgres لأغراض تسويق.
4. التحقق من أصل النطاق وروابط التنزيل وAuth، ومزامنة pending outbox قبل إيقاف القديم.
5. مزودو الرسائل والأجهزة: بيانات اختبار وموافقة صريحة لإرسال فعلي أو دفع.
6. توقيع Windows الموثوق أو قناة Store عند توفر مواردها؛ لا وعود مجانية غير مثبتة.
7. قياس حمل على staging وتحسين تحذيرات RLS بحسب EXPLAIN، ثم تجربة طرح ورجوع قبل البيع.
