# PUSHTORQ — معاينة الهوية قبل الرفع والنشر

تاريخ المراجعة: ٢٧ أكتوبر ٢٠٢٦. هذا فرع محلي في المشروع القائم؛ لم يُرفع إلى GitHub ولم يُنشر، تنفيذًا لطلب عرض التصميم أولًا.

## افتح المعاينة

- `PUSHTORQ-design-board.png`: لوحة مرئية مقترحة للدخول والأعضاء والحضور ولوحة الألوان. هي رسم توضيحي للتصميم، وليست لقطة من نشر جديد.
- `PUSHTORQ-preview.html`: معاينة محلية متعددة الأقسام، تشمل الهوية والدخول ولوحة توضيحية والأعضاء وملف العضو والنموذج والتقرير والموقع. نماذج الأعضاء والدخول والموقع مولدة من مكونات المشروع الحالية. أزرار حفظ المعاينة لا ترسل طلبات؛ البيانات وهمية مولدة في الذاكرة بقواعد المشروع.
- `PUSHTORQ-report-preview.html`: معاينة تقرير منفصل بالهوية الجديدة، دون بيانات عملاء.
- افتح HTML محليًا في المتصفح. لا يوجد رابط معاينة منشور. تعذر فتح file داخل المتصفح السحابي لأن سياسة المتصفح تسمح بـHTTP/HTTPS فقط؛ لم أستخدم التفافًا على هذا القيد. لذلك لا توجد شهادة فحص بصري شامل داخل المتصفح أو على جهاز مادي.

## المرجع والتصميم

المرجع هو صورة الهوية التي أرفقها المالك. الرمز SVG مرسوم رقميًا من جديد بوصفه حرف P مع صاعقة، وليس الملف الأصلي أو مطابقة هندسية تامة له. الاسم النهائي PUSHTORQ، والوصف GYM MANAGEMENT SYSTEM، والشعار POWER YOUR GYM. الألوان الأساسية هي #7C3AED و#A855F7 و#12101C و#F5F3FF؛ الأخضر #22C55E والأحمر #EF4444 والبرتقالي #F97316 للحالات.

الخطوط: Montserrat للعناوين الإنجليزية وInter للنصوص الإنجليزية وCairo للعربية. ملفات الخطوط محلية، مع رخص SIL المرفقة. مصدر Montserrat وInter: مستودع Google Fonts الرسمي (`google/fonts/ofl/montserrat` و`google/fonts/ofl/inter`).

## الملفات والتغطية المحلية

- نظام التصميم: `app/pushtorq-design.css`، مستورد من layout، مع ألوان وحواف وظلال وأزرار وحقول وجداول ودعم تقليل الحركة والطباعة. تهيئة الثيم الافتراضي البنفسجي إلى الوضع الداكن دون إعادة كتابة بيانات العملاء أو إلغاء تخصيصهم.
- المكونات المشتركة: القائمة الجانبية والشريط العلوي والبطاقات والجداول والنوافذ والتحميل والأخطاء والنصوص والإشعارات.
- الدخول والتسجيل واستعادة كلمة المرور، الأندية والاشتراكات التجارية والدعم، صفحة الموقع العربية والإنجليزية والتثبيت وبيانات SEO وOpen Graph.
- شاشة الأعضاء والحضور وملف العضو والنموذج، الاشتراكات والتحصيل والكروت، شاشة العضو، المنتجات والتدريب والموظفون والإعدادات، عبر المكونات المشتركة وملفات CSS الموجودة. لا يعني تحديث مصادرها إتمام قبول كل شاشة بالمتصفح.
- التقارير: تغيير اسم المنتج والعناصر الافتراضية والشعار والترويسات في HTML/Excel، مع استمرار شعار النادي المرفوع وقواعد البيانات المالية والحضور.
- صور التسويق أُعيد تجهيزها كمعاينات تصميم ببيانات توضيحية؛ النصوص صارت تصفها كذلك، ولا تُقدم كصور إنتاجية فعلية.
- manifest وfavicon وأيقونات PWA وأسماء العرض، مع الحفاظ على id وstart_url وscope. أضيف إصدار لروابط الصور وتحديث نسخة كاش الواجهة لتفادي استمرار الشعار القديم، دون تغيير مخزن طابور الحضور.
- Windows وAndroid: مصادر أسماء العرض وأيقونات البدء وأصول اللوجو مهيأة. لم تُستبدل الملفات التنفيذية الموقعة أو يُعلن إصدار جديد. يلزم بناء الحزم والتحقق منها لاحقًا.
- مصادر دليل التشغيل مهيأة للاسم الجديد. أدلة PDF وملفات التنزيل القديمة لم تُعتمد كنسخ PUSHTORQ جديدة.

## أصول الهوية

داخل `public/brand`: نسخ SVG للشعار الداكن والفاتح والأحادي والطباعة، رمز ملون/فاتح/أحادي/طباعة، وأيقونة التطبيق. الكتابة الرئيسية في ملفات الشعار محولة لمسارات لتقليل الاعتماد على الخط عند التضمين.

داخل `public/icons`: PNG بالأحجام 16 و32 و64 و180 و192 و256 و512 و1024، ونسخ الأعضاء والدعم، وmaskable بخلفية معتمة ومساحة أمان. SVG وICO للتبويب، وأصول Windows وAndroid في مساراتها الأصلية.

## ما لم يتغير

لا توجد migration أو عملية حذف أو إعادة تهيئة أو كتابة لقاعدة الإنتاج. جداول gymos ومفاتيح البيئة وX-GymOS-Tenant ومفاتيح التخزين المحلية ومعرفات الحزم والتجميع ومسارات الربط القديمة باقية للتوافق. لم تُعد كتابة قواعد العضويات أو الحضور أو المدفوعات أو صلاحيات المستخدمين أو بروتوكولات الأجهزة. تبقى أسماء الأندية وشعاراتها وبياناتها كما رفعها أصحابها.

- لم يُجر تسجيل دخول أو تحصيل أو حضور تجريبي على قاعدة الإنتاج أثناء مهمة التصميم.
