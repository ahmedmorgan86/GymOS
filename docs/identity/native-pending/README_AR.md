# تحديث Android المؤجل للتوقيع

هذه رقعة الهوية الجديدة لمصادر تطبيقات Android الثلاثة. لم تُطبق على شجرة مصادر الإصدار المنشور حتى تظل ملفات APK المنشورة مطابقة لبصمات مصادرها، وتستمر اختبارات المطابقة الصارمة. واجهة الويب داخل التطبيقات ستستقبل PUSHTORQ من الرابط القديم المحفوظ.

لتحديث اسم وأيقونة التطبيق في نظام Android نفسه: طبّق الرقعة، وابنِ كل تطبيق بمفتاح توقيعه الأصلي، وحدّث versionCode والإصدار وبيانات البصمات الحقيقية، وتحقق من الترقية فوق النسخة الحالية قبل النشر. لا تولّد مفتاحًا بديلًا للحزم الحالية ولا تعدّل sourceHashes لتبدو APK القديمة جديدة.

مفتاح التوقيع وكلمة مروره غير متاحين في البيئة الحالية؛ لا ترسلهما في محادثة أو مستودع عام.
