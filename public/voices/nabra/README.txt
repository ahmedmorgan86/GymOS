This is a single Modern Standard Arabic voice, not a clone of an individual member. It operates locally. Diacritized text is recommended; pronunciation of names and dialects must be previewed.
First use downloads about 45 MB from the GymOS origin. No text is sent to an external voice provider. Browser cache can be cleared by the operating system; first-load internet remains required.
The voice does not install as a system-wide Windows voice. It is available inside GymOS on web and Windows.
